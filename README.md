# UZ Train Seats

Простая отдельная страница для ручного учёта свободных мест на поездах Укрзалізниці.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны.

Данные сохраняются в локальном хранилище текущего браузера. Для резервной копии используйте экспорт CSV.

Можно вставить скопированный список результатов с booking.uz.gov.ua в поле распознавания. Страница добавит распознанные поезда, время, станции и доступность мест по категориям в таблицу.

Источник данных: [booking.uz.gov.ua](https://booking.uz.gov.ua).
